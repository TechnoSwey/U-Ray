Лексика

Числа

· целые: 42, 0, 1234
· вещественные: 3.14, 0.5, 2.0
· не допускаются: 3. (точка без цифры), .5 (точка без целой части)

Строки

Двойные кавычки: "привет". Escape-последовательности:

Запись Значение
\n перевод строки
\t табуляция
\" двойная кавычка
\\ обратный слэш

Перевод строки внутри строки — ошибка.

Булевы

true, false.

Идентификаторы

Буквы (латиница, кириллица), цифры, _. Начинаются с буквы или _. Регистрозависимы.

Ключевые слова

```
print if else while for in break continue
func return import del true false
```

Комментарии

```
// до конца строки
```

Операторы

Арифметические

Оператор Пример Результат
+ 1 + 2 3
- 5 - 3 2
* 2 * 3 6
/ 7 / 2 3.5 (всегда float)
% 10 % 3 1
** 2 ** 10 1024

Унарные

Оператор Пример Результат
- -5 -5
+ +5 5

Унарный минус работает только с числами. -true — ошибка.

Сравнения

Оператор Пример Результат
== 1 == 1.0 true
!= 1 != 2 true
< 2 < 3 true
> 3 > 2 true
<= 2 <= 2 true
>= 3 >= 2 true

== и != работают для любых типов, включая списки и словари (по содержимому, рекурсивно).

Конкатенация строк и списков

```
"a" + "b"      // "ab"
[1, 2] + [3]   // [1, 2, 3]
```

"a" + 1 — ошибка (нельзя смешивать типы).

Приоритеты

От слабого к сильному:

1. == != < > <= >=
2. + -
3. * / %
4. ** (право-ассоциативен)
5. унарные + -
6. постфиксные [i], .attr, (...)

Примеры:

```
-2 ** 2       // -4  (= -(2**2))
2 ** 3 ** 2   // 512 (= 2**(3**2))
2 ** -3       // 0.125
-a[0]         // -(a[0])
```

Переменные и присваивание

```
x = 10
y = x + 5
name = "U-Ray"
```

Присваивание ищет, где переменная уже объявлена (в текущей или внешней области), и обновляет. Если нигде нет — создаёт в текущей.

---

Условия

```
if x > 5 {
    print("больше")
} else {
    print("меньше или равно")
}
```

else опционален. Условие — любое значение: 0, false, "", [], {} — ложны; всё остальное — истинно.

Циклы

while

```
i = 0
while i < 5 {
    print(i)
    i = i + 1
}
```

for по списку

```
for x in [10, 20, 30] {
    print(x)
}
```

for по range

```
for i in range(5)          // 0, 1, 2, 3, 4
for i in range(2, 5)       // 2, 3, 4
for i in range(0, 10, 3)   // 0, 3, 6, 9
for i in range(10, 0, -1)  // 10, 9, ..., 1
```

for по словарю

Итерируется по ключам в порядке вставки:

```
d = {"a": 1, "b": 2}
for k in d {
    print(k, d[k])
}
```

Итерация — по снимку ключей. Удаление/добавление во время цикла безопасно.

break и continue

```
for x in range(10) {
    if x == 3 { break }
    if x % 2 == 0 { continue }
    print(x)  // 1
}
```

break/continue вне цикла — ошибка парсера (с позицией).

Функции

```
func add(a, b) {
    return a + b
}

print(add(2, 3))   // 5
```

· Рекурсия разрешена.
· return без значения возвращает 0.
· Область видимости: функция видит глобальные переменные, но её локальные не «протекают» наружу.
· Вызов как оператор: greet("мир") — работает.

Списки

```
a = [1, 2, 3]
print(a[0])          // 1
a[0] = 10
print(a)             // [10, 2, 3]
print(len(a))        // 3

push(a, 4)
print(a)             // [10, 2, 3, 4]
print(pop(a))        // 4

m = [[1, 2], [3, 4]]
print(m[1][0])       // 3
```

· Индексация с нуля.
· Отрицательные индексы — ошибка.
· Выход за границы — ошибка с позицией.

Словари

```
d = {"name": "U-Ray", "version": 1}
print(d["name"])           // U-Ray
d["version"] = 2
d["new"] = [1, 2, 3]
print(d)                   // {"name": "U-Ray", "version": 2, "new": [1, 2, 3]}

print(keys(d))             // ["name", "version", "new"]
print(has(d, "name"))      // true
del d["new"]
print(len(d))              // 2
```

· Ключи: только str и int. bool/float — ошибка.
· 1 и "1" — разные ключи.
· Порядок вставки сохраняется.
· == — по содержимому, порядок не важен.
· Вложенность: d["a"]["b"] работает, если d["a"] — словарь. Автосоздания нет.
· Вложенные в структуры строки печатаются в кавычках: {"k": "v"}, ["a", "b"].

Ввод-вывод

print принимает любое число аргументов через запятую, печатает через пробел:

```
print(1, 2, 3)              // 1 2 3
print("x =", 5)             // x = 5
print([1, "a", true])       // [1, "a", true]
print({"k": "v"})           // {"k": "v"}
```

str(x) — превращает значение в строку:

```
str(123)          // "123"
str(true)         // "true"
str([1, 2])       // "[1, 2]"
```

Сопоставление с образцом

`match` поддерживает обычные значения, `_` как ветку по умолчанию и
деструктуризацию структур по позиции или имени поля:

```
type Point {
    x
    y
}

p = Point(3, 4)
match p {
    Point(0, _) {
        print("начало координат")
    }
    Point { x: x, y: y } {
        print("точка:", x, y)
    }
    _ {
        print("другой тип")
    }
}
```

Имена полей внутри шаблона связываются только в выбранном блоке. В именованном
шаблоне можно указать только нужные поля; сокращённая запись `Point { x }`
связывает локальную переменную `x` с полем `x`. `_` пропускает значение, а
вложенные шаблоны разбирают структуры рекурсивно, например
`LocatedPoint { label: name, point: Point { x: x, y: _ } }`.

Семантика: ссылки и копирование

· b = a — ссылка (для списков и словарей). push(b, 1) меняет a.
· copy(a) — поверхностная копия. Внешний уровень новый, внутренние — общие.
· == — по содержимому, рекурсивно, безопасно на циклах.
· Циклы: a = []; push(a, a); print(a) → [<cycle>], без падения.

Примеры

```
a = [1, 2]
b = a
push(b, 3)
print(a)          // [1, 2, 3]

c = copy(a)
push(c, 4)
print(a)          // [1, 2, 3]  (не изменился)
print(c)          // [1, 2, 3, 4]

inner = [1]
outer = [inner, 2]
oc = copy(outer)
push(inner, 99)
print(outer)      // [[1, 99], 2]   (inner общий)
print(oc)         // [[1, 99], 2]   (inner общий и в копии)
```
