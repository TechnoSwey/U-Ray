# Инструменты U-Ray

## VS Code

В репозитории лежит локальное расширение
[`vscode/uray-language`](../vscode/uray-language/README.md). Оно регистрирует
`.ur` файлы и включает TextMate-подсветку, комментарии `//`, скобки и
автозакрытие парных символов. Расширение не опубликовано в Marketplace.

## Termux

Для редактирования `.ur` файлов в Termux добавлены настройки подсветки для
nano, Vim/Neovim и micro. Инструкции по установке и копированию конфигураций —
в [`termux/README.md`](../termux/README.md).

## REPL и Tab

Запусти `./uray` или `./uray --repl`. Нажатие Tab дополняет ключевые слова,
встроенные функции, переменные текущей сессии, модули (`nn`, `math`,
`linalg`), а после точки — доступные функции, поля и методы. Подсказки
используют Python `readline`; если Python-сборка не включает этот модуль,
REPL продолжает работать без Tab-дополнения.

Jupyter kernel пока не поставляется. REPL сохраняет окружение между
инструкциями и подходит для интерактивных экспериментов.

## Форматтер

```bash
./uray fmt examples/mlp_xor.ur
./uray fmt --write examples/mlp_xor.ur
./uray fmt --check examples/mlp_xor.ur
```

Без `--write` форматтер выводит результат в stdout и не меняет файл.
`--write` записывает форматированный текст, а `--check` завершается кодом 1,
если файл нужно форматировать. Сначала исходник разбирается парсером;
комментарии и строки сохраняются.

## ML-профилировщик

```bash
./uray profile examples/transformer_sequence.ur --backend=native
./uray profile examples/transformer_sequence.ur --backend=native --format=json
```

Команда запускает программу обычным образом и после её вывода показывает
общее время исполнения, количество вызовов `nn.*`, суммарное, среднее и
максимальное время по операциям, а также краткие описания форм аргументов и
результатов. Профилирование охватывает вызовы ML API из исходника; если
высокоуровневый trainer выполняет внутренние шаги напрямую, они входят в
время строки этого trainer и не выделяются в отдельные операции. Сам
профилировщик добавляет небольшой измерительный overhead, поэтому для
сравнения скорости используй отдельные benchmark-скрипты. При `--format=json`
отчёт остаётся валидным JSON, а вывод программы помещается в `program_output`.

## Статическая проверка

Проверка запускается автоматически до исполнения `.ur` файла. `./uray check
file.ur` проверяет его отдельно, ничего не выполняя. Анализатор выводит
размерности, известные из `nn.dense`, `nn.mlp`, литералов и предшествующих
присваиваний. Он проверяет цепочки `nn.forward`, вход `nn.forward_mlp`, а
также формы `X` и `Y` в `nn.train` / `nn.evaluate`.

Это консервативная проверка: неизвестные значения не объявляются ошибочными,
а остаются под runtime-валидацией. Проверка не заменяет общий вывод типов и
не доказывает корректность произвольных циклов или пользовательских функций.
